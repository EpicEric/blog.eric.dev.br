# blog.eric.dev.br

My personal blog, built with Astro.

> [!Note]
> LLM disclaimer: The frontend of this repo was created with large language models. However, all content in the blog was hand-written.

## Development server

```bash
npm run dev
```

## Build

```bash
nix-build
```

## Publish

```bash
SSH_HOST=... now run publish
```
